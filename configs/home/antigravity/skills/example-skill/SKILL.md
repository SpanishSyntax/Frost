# Example Skill Template

## Summary
This is an example custom skill template for Google Antigravity. Skills provide specialized, multi-step instructions, references, and workflows that extend the agent's capabilities.

## When to Use
- When the user asks for a task matching this skill's specific problem domain.
- When standardized multi-step processes or conventions must be followed.

## Instructions & Workflow
1. **Analyze Requirements**: Parse the input and establish task boundaries.
2. **Execute Steps**: Follow domain-specific guidelines and conventions.
3. **Verify Output**: Run relevant tests, checks, or validation commands.
4. **Deliver Response**: Present the result concisely with clickable file links.
